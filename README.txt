بسته PWA برنامه‌ریز من
=======================
فایل‌ها: index.html (خود برنامه)، manifest.webmanifest، sw.js (کار آفلاین)، چند آیکون و .nojekyll
(فایل .nojekyll مخفی است؛ اگر هنگام کشیدن فایل‌ها نیامد، در GitHub با «Add file ← Create new file» فایلی به همین نام خالی بساز.)

مرحله ۱) بالا آوردن سایت روی GitHub Pages (رایگان)
  - در github.com حساب بساز. فرض کن نام کاربری‌ات ali است.
  - مخزن (Repository) جدید بساز با نام دقیق  ali.github.io  و حالت Public.
    (نام باید همین قالب باشد تا سایت روی ریشه‌ی آدرس بیاید؛ این برای APK بدون نوار آدرس لازم است.)
  - «uploading an existing file» را بزن و همه‌ی فایل‌های این پوشه را بکش (نه خود فایل زیپ). Commit کن.
  - Settings ← Pages ← Source: «Deploy from a branch» ← Branch: main و پوشه / (root) ← Save.
  - بعد از ۱ تا ۲ دقیقه  https://ali.github.io/  باز می‌شود. در کروم گوشی می‌توانی از منو «Install app» را بزنی.

مرحله ۲) ساخت APK با PWABuilder
  - pwabuilder.com ← آدرس سایتت را بده ← Start.
  - در گزارش، مانیفست و Service Worker و HTTPS باید سبز باشند.
  - Package for stores ← Android ← تنظیمات پیش‌فرض را نگه دار، فقط Package ID بده (مثلاً com.ali.planner)
    و برای Signing key گزینه‌ی ساخت کلید جدید ← Generate ← فایل زیپ را دانلود کن.
  - داخل زیپ: فایل APK، فایل کلید (signing key) و فایل assetlinks.json است. کلید را نگه دار؛ برای به‌روزرسانی لازم است.

مرحله ۳) حذف نوار آدرس بالای برنامه
  - در مخزن GitHub: Add file ← Create new file ← نام فایل  .well-known/assetlinks.json  ← محتوای فایل assetlinks.json که از PWABuilder گرفتی را بچسبان ← Commit.
  - اگر این مرحله را انجام ندهی، برنامه کار می‌کند ولی یک نوار باریک آدرس بالایش می‌ماند.

مرحله ۴) نصب
  - APK را روی گوشی بریز و باز کن؛ اندروید اجازه‌ی «نصب از منبع ناشناس» را می‌پرسد.

اطلاعات
  - کارها و یادداشت‌ها روی همان گوشی می‌ماند و جایی آپلود نمی‌شود. فقط خود برنامه روی آدرس عمومی است.
  - آدرس تازه حافظه‌ی جدا دارد. از برنامه‌ی قبلی در «تنظیمات ← دریافت فایل پشتیبان» بگیر و در برنامه‌ی جدید «وارد کردن پشتیبان» بزن.
  - برای به‌روزرسانی برنامه، فقط index.html را در مخزن عوض کن؛ APK را دوباره نساز.
